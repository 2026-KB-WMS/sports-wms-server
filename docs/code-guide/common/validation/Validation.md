# 공통 검증 (validation)

`common/validation/`

## PhoneNumber

| 항목 | 내용 |
|---|---|
| 용도 | 전화번호 형식 검증용 Bean Validation 애노테이션 |
| 규칙 | 하이픈 포함 `지역번호 2~3자리 - 국번 3~4자리 - 4자리` (예: `02-123-4567`, `031-1234-5678`, `010-1234-5678`) |
| 정규식 | `^\d{2,3}-\d{3,4}-\d{4}$` |
| 대상 | 필드, record 컴포넌트, 파라미터 |
| null | 통과한다. 필수 여부는 `@NotBlank`가 따로 정한다 |
| 기본 메시지 | "전화번호 형식이 올바르지 않습니다. 예: 010-1234-5678, 02-123-4567" |
| 사용처 | 창고·지점·공급처·가입 요청 DTO |

## GeoCoordinates

| 항목 | 내용 |
|---|---|
| 용도 | 주소와 함께 저장하는 위도·경도 값 규칙 |
| 상수 | `SCALE = 7` (컬럼 `DECIMAL(10,7)`, 약 1cm) |

| 메서드 | 설명 |
|---|---|
| `isPair(latitude, longitude)` | 둘 다 없거나 둘 다 있으면 true. **쌍으로만 입력**할 수 있다 |
| `scale(value)` | 소수 7자리로 `HALF_UP` 반올림. 지도 API가 7자리를 넘겨줘도 거절하지 않는다. null이면 null |
